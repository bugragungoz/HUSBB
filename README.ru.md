HUSBB - нативное приложение для Windows (Rust, egui на wgpu) для осциллографа **Hantek DSO2D15**.
Оно читает оба канала из одного и того же сбора данных по USB и рисует их так же, как сам
осциллограф: с измерениями, курсорами по реальным отсчётам, маркерами, заморозкой экрана, экспортом
в один клик и органами управления осциллографа - без ПО Hantek для ПК. Написано для DSO2D15 и
проверено только на нём.

## Зачем это нужно

На прошивке **3.0.1 (2025-04-18)** собственное ПО Hantek для DSO2D15 ничего не показывает: оно
запрашивает `PRIVate:WAVeform:DATA:ALL?`, а эта прошивка на такой запрос больше не отвечает.
Документированная команда `:WAVeform:DATA:ALL?` отвечает, но при двух включённых каналах передаёт
один и тот же канал дважды.

Реверс-инжиниринг прошивки DSO2D15 выявил команду `:WAVeform:DATA:DISP?`: она отдаёт каждый
включённый канал, каждый из своего буфера одного и того же сбора, - ровно ту запись, которую
осциллограф сейчас рисует. HUSBB использует её, поэтому нет переключения каналов, нет потерянных
отсчётов (все 3850 точек экрана на канал) и сохраняется реальное временное соотношение между CH1 и
CH2. Прошивка также показала, почему передняя панель блокируется, пока подключён ПК, и как вернуть ей
управление. Подробности: [docs/PROTOCOL.md](docs/PROTOCOL.md) (на английском).

## Возможности

- **Оба канала в реальном времени**, в цветах самого осциллографа (CH1 жёлтый, CH2 зелёный), около
  1,5 новых записей в секунду - собственный предел DSO2D15 по USB.
- **Переключатель Live link.** Выключен: HUSBB ничего не отправляет, и примерно через 5 с DSO2D15
  разблокирует переднюю панель, так что можно пользоваться его кнопками. Включён: HUSBB снова берёт
  управление.
- **Управление:** run / stop, single, auto setup, включение/выключение каналов, V/div, смещение,
  time/div, источник, фронт, режим и уровень синхронизации. Каждое изменение считывается обратно с
  осциллографа.
- **View** для каждого канала: показать или скрыть осциллограмму только в HUSBB.
- **Измерения** для каждого канала: частота, период, коэффициент заполнения, Vpp, Vmax, Vmin, Vavg,
  Vrms; по желанию выводятся и поверх экрана.
- **Курсоры Track**, привязанные к реальным отсчётам и считывающие оба канала в точках A и B (dt,
  1/dt, dV), а также курсоры напряжения.
- **Маркеры:** двойной щелчок по осциллограмме отмечает отсчёт (время и напряжение); правый щелчок
  удаляет маркер.
- **Hold** замораживает экран, пока осциллограф продолжает работать.
- **Export** в один клик в папку, выбранную в настройках (PNG экрана и/или CSV с данными), или
  **Save as...** в любое место.
- Показ времени и напряжения под курсором мыши, автоматическое переподключение, запоминание
  настроек.

## Скачать

[**HUSBB.exe**](https://github.com/bugragungoz/HUSBB/releases/latest) в разделе Releases: один файл,
без установщика. Кроме него нужен только VISA (см. ниже). Exe не подписан, поэтому Windows
SmartScreen может один раз спросить: *Подробнее* -> *Выполнить в любом случае*.

## Требования

- Windows 10 или 11, 64 бита, и Hantek DSO2D15 (проверено на прошивке 3.0.1(250418.00)).
- VISA с поддержкой USBTMC, чтобы осциллограф появился в Диспетчере устройств в разделе *USB Test
  and Measurement Devices*: Keysight IO Libraries или R&S VISA (проверено с R&S VISA 7.2 и
  драйвером IVI `ausbtmc`). HUSBB загружает `visa64.dll` во время работы.
- **Задний** порт USB-B осциллографа.

### Если DSO2D15 постоянно отключается

На ноутбуке, где все порты USB 3.x, DSO2D15 отваливался от шины через 30 с - 5 мин, даже совсем без
обмена данными и при работе от батареи (Windows записывает событие Kernel-PnP 1010, *"surprise
removed as it is reported as missing on the bus"*). **Простой USB 2.0-хаб между ноутбуком и
осциллографом решил проблему.** `tools/idle_watch.ps1` воспроизводит этот тест.

## Сборка и запуск

С [Rust](https://rustup.rs) (stable, toolchain MSVC):

```bash
cargo build --release
```

```bash
target\release\HUSBB.exe
```

Параметры командной строки, в основном для автоматизации:

```
--resource <имя VISA>      использовать этот осциллограф вместо первого найденного
--screenshot <файл.png>    сохранить окно через --after секунд (по умолчанию 8) и выйти
--cursors track|voltage    запустить с включёнными курсорами
--tab measure              запустить на вкладке Measure
```

Проверка с оборудованием (при подключённом DSO2D15):

```bash
cargo run --example probe
```

```bash
cargo run --example link
```

Модульные тесты работают на пакетах, записанных с настоящего DSO2D15 (`tests/data`):

```bash
cargo test
```

## Структура

| | |
|---|---|
| `src/visa.rs` | привязка к VISA, загружается во время работы |
| `src/protocol.rs` | разбор потока `:WAVeform:DATA:DISP?` |
| `src/scope.rs` | команды и настройки DSO2D15 |
| `src/acquire.rs` | поток сбора данных, live link, переподключение |
| `src/measure.rs` | измерения, форматирование в СИ |
| `src/ui/` | окно, экран осциллографа, курсоры, маркеры, органы управления (дизайн-система "Bugra") |
| `docs/PROTOCOL.md` | что показал анализ прошивки |

## Как это сделано

HUSBB создан с помощью **Claude Opus 5.5**. Протокол DSO2D15 восстановлен реверс-инжинирингом
оригинального обновления прошивки осциллографа и ПО Hantek для ПК - только статический анализ
файлов; в осциллограф ничего не записывалось и не прошивалось.
